# ShopNest AI Pro-Level User Interface Architecture

This directory implements the Pro-Level UI design system powering ShopNest's 5 AI experiences:
1. **AiAdvisorView.tsx** — Customer & Guest Shopping Advisor (Cosmic Violet Holographic)
2. **AiCommerceCopilot.tsx** — Admin Copilot (Cyber Amber), Seller Copilot (Neon Emerald), Customer Copilot (Electric Indigo)
3. **DeliveryCopilotFloatingWidget.tsx** — Logistics & Courier Radar (High-Octane Cyan)
4. **AiActionConfirmationModal.tsx** — Glassmorphic Action Verification Modal

## UI/UX Highlights
- **Ultra-Glassmorphism**: Multi-layered backdrop-blur, dark slate translucency, and dual-tone borders.
- **Ambient Radial Glow Orbs**: Theme-specific color auras creating realistic depth.
- **Kinetic Waveform Typing State**: Animated bouncing bars with multi-phase contextual messages.
- **Ground-Truth Evidence Badges**: Collapsible verified database fact inspection cards.
- **Omni-Device Responsiveness**: Seamless bottom-sheet docking on mobile, slide-over on tablet, floating on desktop.
